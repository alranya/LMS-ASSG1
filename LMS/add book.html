Admin Guidelines

When adding new books to the engineering library portal, please ensure:

  • The Accession ID / ISBN matches the barcode sticker on the physical textbook.
  • Select the correct Engineering Branch so students can easily filter and locate resources.
  • Keep the Number of Copies accurate based on physical stock received from publishers.
